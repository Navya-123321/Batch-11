# Sales Data Analysis Dashboard

## Project Overview
The Sales Data Analysis Dashboard is developed using Python, Streamlit, Pandas, and Matplotlib. It helps analyze sales data and understand business performance through interactive visualizations.

## Technologies Used
- Python
- Streamlit
- Pandas
- Matplotlib
- Excel

## Dataset
The project uses an Excel dataset containing 1000 sales records, including:
- Order ID
- Order Date
- Customer Details
- Product Category
- Region
- Quantity
- Sales
- Profit

## Features
- Upload and analyze Excel files
- View sales data
- Analyze sales by region
- Analyze sales by category
- Analyze sales by product
- Visualize sales using charts
- Understand sales and profit performance

## How to Run the Project

1. Install Python.
2. Install the required libraries:

   `pip install -r requirements.txt`

3. Run the application:

   `streamlit run app.py`

4. Open the local URL displayed in the terminal.

## Project Outcome
This dashboard helps users understand sales performance and make better business decisions using data visualization.
